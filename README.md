# CppBook Documentation Site

Static documentation/release site for CppBook.

## Structure

- `index.html` — documentation page
- `assets/style.css` — styling
- `assets/app.js` — active navigation
- `downloads/` — place your actual Windows installer here

## Add the installer

Copy your generated file:

`CppBook Setup 1.0.0.exe`

into:

`downloads/CppBook Setup 1.0.0.exe`

The Download button on the site will then work automatically.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server.
